# 우가누가! — 누가 공주 구출 대작전

고인돌1 직접 플레이와 제공 영상을 참고해 다시 구현한 PC 1인 횡스크롤 액션 게임입니다. 우가가 누가 공주를 구하러 떠납니다. 원본 그림·음원·코드는 사용하지 않습니다.

## 실행

```sh
npm install
npm run dev -- --port 5196
npm run build
```

## 조작

- ← → 이동, ↑ 점프·사다리 상승, ↓ 동굴 진입·사다리 하강·통나무 발판 내려가기
- X 몽둥이 던지기(화면에 한 개).
- 일반 맵에서 가끔 나오는 나무·돌·뼈·불 몽둥이를 주우면 바로 장착합니다. 돌은 느리고 강하며, 뼈는 길고 빠릅니다. 몬스터를 고기로 만들 때도 낮은 확률로 무기가 추가로 나옵니다.
- 물속에서는 방향키로 상하좌우 헤엄칩니다. 숨은 20초이며 수면이나 공기 주머니에서 회복합니다. 숨이 떨어지면 체력이 1초에 1씩 줄어듭니다.
- 18스테이지 하늘섬은 구름 발판 10개를 잇는 공중 맵입니다. ↑ 점프 후 길게 눌러 활공하고, 화살표가 올라가는 상승기류 9곳으로 높은 구름을 건넙니다. 착지한 발판에서 재시작합니다.
- Space 공격. 길게 눌렀다 놓으면 강공격. ↑+공격은 위쪽 공격.
- 기절한 적에게 접근하면 먹이와 점수를 얻습니다. 먹이를 모아 깃발로 이동합니다.
- 동굴은 왼쪽 입구로 걸어 나옵니다. 지나온 길로 돌아갈 수 있으며, 재방문해도 수집한 아이템은 복구되지 않습니다.
- Esc/P 일시정지, M 음소거, 일시정지 중 Q 시작 화면. 게임패드 지원.

## 진행과 그림

일반 몬스터는 맵당 8마리로 배치하며, 길목 수문장·샛길 보물 지킴이·공중 경비로 역할을 나눕니다. 시작 지점과 입구 주변에는 쉬는 구간을 두고 화면 내 새 적은 최대 두 마리까지 등장합니다. 보스 준비에 필요한 먹이는 60입니다. [배치 조정 내역](art-src/encounter-balance-v1/README.md)을 참고하세요.

20개 맵에는 서로 다른 이동·환경 기믹이 적용됩니다. 화산 분출 타이밍, 빙판 제동, 모래바람, 늪, 도약 발판, 수정 공명, 파도, 버섯 반동, 유적 압착 장치, 낙뢰, 폭포, 낙엽 활공, 오로라 중력, 화산재, 수영, 구름 이동, 별똥별, 꽃길 회복을 사용합니다. 화면과 일시정지 메뉴에서 현재 규칙을 확인할 수 있습니다. 전체 목록과 검증 방법은 [스테이지 기믹 안내](art-src/stage-patterns-v1/README.md)에 있습니다.

서로 다른 배경의 20개 스테이지를 순서대로 탐험합니다. 1~19스테이지는 마지막 공터에서 보스를 만나고, 20스테이지 새벽 정원에서 누가 공주를 구출합니다. 정글·화산·빙하의 단차, 구덩이, 물 발판, 사다리, 동굴, 가시, 곰·멧돼지·공룡·익룡·거미가 등장합니다.

캐릭터 편집 원본은 `art-src/pixelorama/`, 게임 자산은 `public/assets/animation-v5/`입니다. 11캐릭터99동작을 캐릭터별11개 무손실 아틀라스로 연결합니다. 지상9종은 전신 교대 보행8프레임을 사용하며 이족 교차·사족 교대·거미 교대 지지를 구분합니다. 표시·충돌 크기는 이전의75%입니다. 편집 원본의 넓은 투명 여백을 유지하고 게임용 아틀라스에서만 빈 공간을 줄입니다. Pixelorama 편집·AI 연결은 `tools/SPRITES.md`를 따릅니다. 전신 그림과 프레임별 시간을 유지하고 반복/일회 동작을 구분합니다. 시작화면과 꿈 원화는 이전 그림을 유지합니다. 인게임 맵은 `src/game/pixelMap.ts`의 픽셀 지형·사다리·소품과 `art-src/pixel-map/`의 숲·화산·설산 배경(384×216, 48색)을 사용합니다. 탐험맵은 3층 경로·계단형 돌출 지형과 수직 카메라를 사용합니다. 사다리는 지형을 지우지 않는 전경 레이어이며 등반 중 바위 충돌을 무시하고 연결된 발판에 착지합니다. 일반 몬스터는 지역별로 순찰·단거리 추격·도약·매복·돌진·급강하·활공·원거리 보초 패턴을 사용합니다. 공격 예고와 회복 시간이 있고 피격·기절 중에는 공격을 멈춥니다. 보스는 기존 접촉 전투를 사용합니다. 시작화면·꿈 원화는 유지합니다.

동작은 이동거리·수직속도·지면충돌·공격진행도에 맞춰 재생합니다. 기절한 몹은 쓰러짐→기절→회복, 보스는 예고→공격→착지/빈틈으로 연결합니다. 애니메이션 패킹은 `tools/pack_art.py --animation`이며 그림 수·완전중복·투명여백·원본 가장자리 절단을 검사합니다.

그림을 다시 압축할 때는 Pillow·NumPy·SciPy가 있는 Python으로 `tools/pack_art.py`를 실행합니다. Vue3·TypeScript·Vite 기반이며 저장되는 정보는 최고 점수입니다.


스테이지 배경은 `src/game/background.ts`에서 관리합니다. 1~20 모두 개별 제작한 배경 원화를 사용합니다. PNG 원본·생성 프롬프트·전체 미리보기는 `art-src/stage-backgrounds-v1/`, 게임용 WebP 20장과 전용 매니페스트는 `public/assets/stage-backgrounds-v1/`에 보관합니다. 스테이지 목록과 경로는 `src/game/stages.ts`에 있으며 개발 화면 하단 버튼으로 20개 스테이지에 바로 이동할 수 있습니다.


몬스터 추가 원화 10종(160자세)과 편집용 시트는 `art-src/monsters-v9/`, 게임용 파일은 `public/assets/monsters-v9/`에 있습니다. `BESTIARY`·`HABITATS`와 지역 전용 캐스트를 조합해 20개 스테이지를 배치합니다. 실제 배치 좌표·행동·그룹은 `art-src/monsters-v9/stage-encounters.json`, 행동·배치 검증은 `node tools/check_encounters.mjs`로 확인합니다.


전경 지형은 `src/game/terrainThemes.ts`의 20개 지역 테마를 사용합니다. 지역마다 바닥 재질·표면·발판·지지 구조물·등반로를 따로 그렸으며, 숲 이외 지역은 현무암·빙하·사암·수정·석조 유적·산호암 등으로 표시합니다. PNG 원본·최종 생성 프롬프트·전체 도감은 `art-src/terrain-v10/`, 게임용 WebP 120개는 `public/assets/terrain-v10/`에 있습니다. 재패킹은 `python tools/pack_terrain_v10.py`로 실행합니다(Pillow·NumPy·SciPy 필요).


동굴은 시작 화면을 지난 탐험 구간에 스테이지마다 2~4곳 배치합니다. 입구는 지역별 동굴 원화를 사용하고 내부 벽·바닥은 주변 지역의 재질을 이어 씁니다. 처음 들어갈 때 시계·십자가·고기·사과 중 1~3개를 무작위로 정합니다. 시계는 시간 +10, 십자가는 목숨 +1(최대 9), 고기는 먹이 +20·체력 회복, 사과는 먹이 +5·점수 보너스입니다. 동굴마다 보상 상태가 독립적으로 유지되어 재방문해도 다시 생기지 않습니다. 검증은 `node tools/check_caves.mjs`, 배치 좌표는 `shots/caves/placement-report.json`에서 확인할 수 있습니다.
몽둥이 획득: 맵 고정 배치를 제거하고 일반 몬스터를 완전히 처치했을 때 3% 확률로 추가 드롭한다. 돌 1.2%, 뼈 0.9%, 불 0.6%, 나무 0.3%. 획득 시 자동 장착, 캐릭터 무기 이미지와 HUD/투사체 반영, 2.4초 획득 배너를 표시한다. 검증: node tools/check_weapon_pickups.mjs.

지형 렌더링 점검: `node tools/check_terrain_rendering.mjs`는 20개 맵의 발판 907구간, 받침 없는 발판, 사다리 80개 길이, 장식의 발판 위 돌출 방지, 추가 구조물 9종의 갓/상판 비율을 확인한다. 브라우저 비교 화면은 `shots/terrain-audit/preview.html`에 있다. 지역별 발판은 양 끝을 한 번만 그리고 가운데를 연결하며, 사다리는 가로대 간격을 유지해 반복한다.
