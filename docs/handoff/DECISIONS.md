- 기획안 A·B를 예전 엔진에 적용한다(대표: 「어제 내가 준 md파일적용하면 되겠네」). 순서는 `LEAD_298_수정계획.md`.

## 게임 규칙
- 1인용. 2P(부가) 없음. 던지기 없음. 몹은 부딪히면 공격, 맞으면 경직.
- 시간: 모든 판 60, TIME UP 뒤 +20, 시계 +10, 표시 1 = 3.6초 (대표 「60으로 하자」).
- FOOD 최대 60, 가득 차야 보스 문 열림. 먹이 +5/+20/+40.
- 점수는 예전 엔진 기존 값 유지(Phaser 임시 점수로 덮어쓰지 않음).
- 15판 최종 보스는 **킹콩**(대표 「킹콩이 최종 보스」). 패턴: 가슴 두드리기 충격파 / 돌진→벽 충돌 어지러움 / 뛰어 내려찍기, 체력 절반 이하 분노, 처치 후 누가 구출. 보스 HP는 머리 위에만.
