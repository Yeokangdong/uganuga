# 우가누가! — 게임 화면·연출 개선 기획안

> 작성일: 2026-11-03  
> 목적: 현재 정글 스테이지 화면의 허전함을 줄이고, **우가가 킹콩에게 납치된 누가를 구하러 간다**는 목표와 액션의 재미를 분명하게 보여준다.  
> 기준 자료: 사용자가 제공한 `우가누가_게임기획서.md`, 현재 게임 화면 이미지  
> **표기 규칙**: **[확정]**은 기존 기획서·대화에서 정해진 내용, **[제안]**은 이 문서의 신규 개선안이다. 제안은 승인 전까지 확정 규칙으로 취급하지 않는다.

---

## 1. 게임 정체성

### 1.1 핵심 콘셉트 [확정]

- 게임명: **우가누가!**
- 주인공: **우가** — 주황색 머리, 표범무늬 옷, 나무 몽둥이를 든 원시인 소년
- 구출 대상: **누가** — 납치된 공주
- 납치범: **킹콩** — 오프닝에서 누가를 낚아채 감
- 장르: **1인용 2D 횡스크롤 액션 플랫포머**
- 구성: **15판 + 최종 보스 + 구출 엔딩**
- 방향: 고인돌·Joe & Mac풍의 밝고 코믹한 원시시대 액션
- 플랫폼/엔진: 웹 브라우저, **Phaser 3 + Tiled**

**플레이어에게 전달해야 할 한 문장:**

> “우가가 먹이를 모으고 위험한 원시 세계를 돌파해, 킹콩에게 납치된 누가를 구한다!”

### 1.2 이번 개선의 핵심 [제안]

**빈 화면을 UI로 덮지 않는다.** 플레이 공간에는 **이동 경로를 안내하는 먹이·적·지형 소품·코믹한 움직임**을 배치하고, 상단 HUD는 **현재 상태와 구출 목적**만 간결하게 표시한다.

## 2. 유지해야 할 기존 게임 규칙 [확정]

| 구분 | 기존 규칙 |
|---|---|
| 기본 조작 | ← → 이동 / ↑ 점프·사다리 / Space 몽둥이 공격 |
| 투척 | 없음. 새 투척 무기/조작을 임의 추가하지 않음 |
| 시간 | 모든 판 표시 **60**에서 시작. 표시 1 = 실제 3.6초 |
| 시간 소진 | 0이 되면 TIME UP 후 **20** 추가 |
| 시계 아이템 | 시간 **+10** |
| FOOD | 최대 **60**, 먹이 획득 시 **+5 / +20 / +40** |
| 보스 문 | FOOD가 **60으로 가득 차야 열림** |
| 동굴 | 판마다 입구 위치가 다르며 보너스 공간으로 연결 |
| 목숨 | 동굴에서 추가 가능. 부활점에서 불꽃 연출과 함께 부활 |
| 보스 HP | **보스의 머리 위에만** 표시. 상단 HUD에 별도 보스 HP를 만들지 않음 |
| 시간 보너스 | 판 클리어 시 남은 시간 × 10점 |
| 수우쿠렛 | 1판당 1~2마리. 순수 개그용이며 **피해도 점수도 없음** |
| 연출 | 킹콩 납치 오프닝, 15판 여정, 구출 엔딩 유지 |

> 참고: 기존 스크린샷 우상단에 `163`이 보이지만, **기획서에 확정된 시작 시간은 60**이다. 화면과 실제 런타임을 검수해 일치시킨다.

## 3. 현재 정글 화면 진단

### 3.1 좋은 점

- 원경의 산·구름·숲과 근경의 발판이 분리되어 정글의 깊이감이 좋다.
- 잔디 발판, 덩굴 사다리, 동굴이라는 핵심 지형이 이미 구분된다.
- 주인공의 표정과 색상이 밝아 가족용 코믹 액션에 어울린다.
- 화면 왼쪽 HUD에 SCORE·HP·FOOD·LIFE·STAGE·무기 정보가 이미 있다.

### 3.2 아쉬운 점

| 관찰 | 플레이 측면의 문제 | 대응 방향 |
|---|---|---|
| 넓은 공중 구간에 아이템이 없음 | 어디로 점프할지 유도 부족 | 먹이 수집 경로로 점프선 설계 |
| 플랫폼 위가 대부분 비어 있음 | 전투·탐험의 리듬이 약함 | 적·먹이·상자 대신 적절한 지형 소품 배치 |
| 동굴이 검은 구멍으로만 보임 | 접근 동기·정체가 약함 | 지형에 맞는 흔적과 진입 피드백 |
| 배경이 정지된 그림처럼 보임 | 생태계가 죽어 보임 | 나비·나뭇잎·덩굴·작은 동물 등 저강도 환경 애니메이션 |
| SCORE는 있지만 눈에 덜 띔 | 보상을 체감하기 어려움 | 획득 위치의 떠오르는 점수 텍스트 |
| 구출 목표가 HUD에 보이지 않음 | 왜 전진하는지 잊기 쉬움 | 누가 초상/구출 상징을 절제해서 추가 |

## 4. HUD 리디자인 [제안]

기존 나무판과 뼈 장식의 원시시대 분위기를 유지한다. 폰트와 아이콘은 기존 기획서대로 **그림 글자**를 사용한다. 배경을 가릴 만큼 큰 패널은 피한다.

### 4.1 권장 레이아웃

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ [우가 얼굴] HP ■■■■■■  FOOD 35/60  LIFE ×3  │ STAGE 01 │ [누가♥] │ TIME 60 │
│                                      SCORE 004330                          │
│                                                                               │
│                   [먹이]       [먹이]      [먹이]                              │
│                    ●            ●           ●                               │
│                          우가                                                │
│                         ──────┐                                              │
│         ●   ●      ──────     │       [작은 적]             [동굴]             │
│       ────────────            │       ──────────           ┌──────┐            │
└───────────────────────────────────────────────────────────────────────────────┘
```

*도식은 개념도이며 실제 위치·충돌 좌표를 의미하지 않음.*

### 4.2 표시 항목

| 구역 | 항목 | 방식 | 우선순위 |
|---|---|---|---|
| 좌측 | 우가 얼굴, HP, FOOD, LIFE | 기존 표시 유지·글자 약간 확대 | P0 |
| 중앙 | `STAGE 01`, `SCORE 004330` | 한눈에 식별되도록 정렬 | P0 |
| 중앙의 작은 보조 영역 | 누가 얼굴 + 하트/구출 표식 | **구출 동기** 상기. 진행도 수치는 아직 미확정 | P1 |
| 우측 | `TIME 60` | 돌판 모양 유지, 읽기 쉬운 숫자 | P0 |
| 상황 알림 | `FOOD FULL!`, `TIME UP`, `STAGE CLEAR` | 짧고 강한 팝업 | P0 |

### 4.3 바꿔야 할 세부사항

1. SCORE를 분리해 표시하더라도 **같은 정보를 두 번 표시하지 않는다**.
2. FOOD는 숫자 `35/60`과 게이지를 함께 보여주면 목표가 분명해진다.
3. 보스 문이 열리는 순간 `FOOD FULL!` + 문 열림 효과를 동기화한다.
4. 타이머는 실제 기획 규칙대로 `60`에서 시작한다.
5. 상단 HUD에는 정보를 추가하되 **캐릭터와 발판에 겹치지 않도록 안전 여백**을 둔다.
6. 보스 HP는 기존 규칙대로 머리 위에만 표시한다.

## 5. 정글 1판 오브젝트 배치 [제안]

### 5.1 배치 원칙

- 우가가 이동하는 **주 경로에 먹이**를 두고, 점프를 요구하는 높은 경로에는 조금 더 매력적인 먹이 묶음을 배치한다.
- 먹이는 기존 FOOD `+5 / +20 / +40` 체계 내에서만 사용한다.
- 시작점·부활점·사다리 출입구·필수 착지점은 위험 오브젝트를 비워 둔다는 기존 규칙을 지킨다.
- 적은 반드시 땅이나 지정된 공중 출현 지점 등 **기획된 위치**에 존재하도록 한다. 갑자기 겹쳐 나타나지 않게 한다.
- 동굴 진입을 막는 장식이나 큰 덤불을 두지 않는다.

### 5.2 스크린샷 기준 구역별 개선

| 화면 구역 | 현재 상태 | 신규 배치안 |
|---|---|---|
| 왼쪽 상단 HUD 아래 | 원경이 넓게 노출 | 나뭇잎 2~3개가 천천히 떨어지는 효과. 조작 가독성 유지 |
| 왼쪽 중단 공중 | 큰 여백 | 아래 발판에서 위 발판으로 이어지는 **먹이 3~5개 곡선** |
| 중앙 아래 발판 | 거의 빈 잔디 | 작은 돌 1~2개, 꽃 2~3송이, 먹이 소량 |
| 중앙 우가 근처 | 단일 캐릭터만 보임 | 바로 앞엔 안전 공간. 조금 뒤에 첫 번째 쉬운 적 배치 |
| 오른쪽 긴 덩굴 기둥 | 등반 지형 중심 | 덩굴 흔들림, 위쪽 먹이 경로. 사다리 동선 확보 |
| 오른쪽 하단 동굴 | 내부가 완전히 검음 | 발자국·부서진 가지·작은 뼈 표지 정도로 입구 의미 강화 |
| 배경 중거리 | 아름답지만 정적 | 멀리 날아가는 익룡/나비 등 **저속 비상호작용 레이어** |

### 5.3 밀도 가이드

한 화면에서 시선을 사로잡는 상호작용 대상은 대략 **3~6개 무리**로 제한한다. 배경 소품은 지나치게 촘촘하게 넣지 않는다. 주인공, 적의 공격 예고, 먹이, 발판 경계의 가독성이 언제나 우선이다.

## 6. 점수와 수집 피드백

### 6.1 즉시 적용 가능한 연출 [제안]

- 점수 대상 이벤트가 발생하면 해당 위치에서 `+점수`가 **살짝 위로 떠오르며 0.5~0.8초 내 사라진다**.
- 먹이 획득 시 `FOOD +5`, `+20`, `+40` 중 해당 값을 작게 표시한다.
- 몽둥이 적중 시 가벼운 화면 흔들림/타격 정지/작은 별 효과를 적용한다.
- FOOD가 60에 도달하면 게이지가 한 번 반짝이고 보스 문이 열리는 방향을 짧게 안내한다.
- 시간 보너스는 클리어 결과 화면에서 **남은 시간 × 10** 계산 과정을 보여준다.

### 6.2 점수 규칙의 주의점

**기획서에 확정된 점수 공식은 `남은 시간 × 10점`뿐이다.** 먹이·일반 적·연속 처치의 점수는 기존 자료에 수치가 없어 이 문서에서 임의로 확정하지 않는다.

| 점수 이벤트 | 상태 | 제안 |
|---|---|---|
| 남은 시간 × 10점 | **확정** | 클리어 화면에서 계산식 표시 |
| 먹이 수집 점수 | 미정 | FOOD 증가와 점수 지급 여부를 별도 결정 |
| 적 처치 점수 | 미정 | 수치를 기획 확정 후 팝업 연결 |
| 연속 처치 콤보 | 신규 아이디어 | 기초 액션이 안정된 뒤 P2로 검토 |
| 수우쿠렛 구경/발견 | **0점 확정** | 점수 팝업 절대 표시하지 않음 |

## 7. 킹콩·누가 구출 동기 강화

### 7.1 기존에 확정된 이야기

1. 오프닝에서 **킹콩이 누가를 납치**한다.
2. 우가가 15개 지역을 모험한다.
3. 최종 보스 이후 누가를 구출하고 결과 화면으로 이동한다.

### 7.2 새 연출 아이디어 [제안]

- **스테이지 시작:** 1~2초 정도의 짧은 누가 초상 또는 '구출' 아이콘을 보여준다. 반복 관람의 피로를 줄이기 위해 스킵 가능하게 설계한다.
- **정글의 흔적:** 누가가 흘린 작은 머리장식·꽃 또는 거대한 발자국을 배경 소품으로 활용한다. *수집 필수 아이템으로 바꾸지 않는다.*
- **구출 목표의 재등장:** 특정 전환 장면에서만 킹콩의 실루엣을 멀리 보여준다. 주행 중 반복되는 대형 전경 연출은 조작과 시야를 해치므로 지양한다.
- **스테이지 클리어:** `STAGE CLEAR`와 함께 누가가 있는 방향을 암시하는 간단한 컷을 넣을 수 있다.
- **최종장:** 킹콩이 최종 보스인지 여부는 기존 문서에 명시되어 있지 않으므로 **추후 결정 필요**. 현재 확정된 것은 ‘킹콩 = 납치범’이라는 점이다.

**권장 톤:** 공포보다 **과장된 표정, 코믹한 실수, 명료한 악당 연출**을 우선한다.

## 8. 수우쿠렛 연출 상세

### 8.1 캐릭터 규칙 [확정]

- **수우쿠렛**은 길고 마른 미어캣이며, 우가누가만의 독창적인 캐릭터다.
- 화면 구성에 맞는 **굵은 갈색 외곽선 + 평평한 채색**을 사용한다.
- 매 판 처음부터 **1~2마리** 배치한다. 갑자기 스폰하지 않는다.
- 애벌레를 좇고, 넘어지고, 애벌레를 껴안고 숨긴다.
- 우가가 가까이 오면 깜짝 놀라 달아나고 **해당 판에 다시 등장하지 않는다**.
- **피해도 점수도 없다.** 적/아이템으로 바꾸지 않는다.
- 영화 스크렛의 에셋·캐릭터 형태를 직접 복제하지 않는다.

### 8.2 1판 권장 장면 [제안]

1. 우가보다 조금 앞쪽, 안전한 발판에 수우쿠렛이 애벌레를 바라보고 있다.
2. 애벌레가 고개를 들자 수우쿠렛이 큰 눈으로 주변을 확인한다.
3. 애벌레를 덥석 붙잡으려다 **뒤로 벌러덩** 넘어진다.
4. 우가가 접근하면 눈이 커지고 애벌레를 품에 안은 채 허겁지겁 달아난다.
5. 도망친 뒤에는 해당 스테이지에서 다시 나타나지 않는다.

### 8.3 판별 반응 [확정]

| 환경 | 반응 |
|---|---|
| 용암 | 엉덩이를 데여 로켓처럼 솟구침 |
| 얼음 | 얼었다 깨지거나 미끄러져 빙글 돎 |
| 물 | 볼을 빵빵하게 하고 헤엄 |
| 낭떠러지 | 이빨로 바위에 매달림 |

**연출 우선순위:** 입장 애니메이션을 길게 늘리기보다, 멀리서도 읽히는 **큰 실루엣과 표정**을 우선한다.

## 9. 15판의 정체성 유지 [확정]

기존 기획서의 **등장체·위험 행동·회피법**은 변경하지 않는다. 정글 화면 개선을 나머지 판에 복사할 때는 아래 테마에 따라 시각 오브젝트만 교체한다.

| 판 | 지역 | 기존 고유 등장체 |
|---|---|---|

## 10. 기술 적용 가이드 [제안]

### 10.1 Phaser 3 구현 계층

1. **Background** — 먼 산, 안개, 구름 등의 패럴랙스 레이어
2. **Ambient** — 나비/나뭇잎/흔들리는 덩굴 등 충돌 없는 반복 연출
3. **World** — Tiled 타일맵, 발판, 사다리, 동굴, 보스 문
4. **Gameplay** — 우가, 먹이, 몬스터, 수우쿠렛
5. **Feedback** — 타격 이펙트, FOOD 팝업, 문 열림 알림
6. **HUD** — 카메라 이동과 무관하게 고정되는 화면 정보

**주의:** 실제 프로젝트 폴더 구조와 클래스 이름은 파일을 직접 확인하기 전까지 새로 지어 확정하지 않는다.

### 10.2 기능별 세부 작업

| 작업 | 구현 설명 | 완료 기준 |
|---|---|---|
| HUD 시간 정합성 | 타이머 시작 숫자 60 확인 | 최초 표시 및 TIME UP 처리 정상 |
| 점수 가독성 | SCORE의 위치·크기 조정 | 액션 중에도 즉시 읽을 수 있음 |
| FOOD 상태 | 0~60 표시, 획득 팝업 | +5/+20/+40과 UI 수치가 일치 |
| 보스 문 알림 | FOOD 60 도달 시 반응 | 문 열림 상태와 이펙트가 동기화됨 |
| 먹이 배치 | Tiled에 수집 경로 설계 | 주요 점프가 자연스럽게 안내됨 |
| 동굴 표지 | 주변 소품·약한 빛 효과 | 입구가 다른 지형보다 쉽게 식별됨 |

| 누가 구출 표식 | HUD 보조 아이콘 | 주요 UI와 겹치거나 시야를 가리지 않음 |

## 11. 개발 우선순위

### P0 — 출시 전 필수 정합성·가독성

1. 현재 실행 화면의 시간 숫자를 **기획서의 60 시작 규칙과 일치**시키기.
2. SCORE, FOOD, HP, LIFE, STAGE, TIME 정보를 정돈하되 중복 표시 제거.
3. FOOD=60일 때만 보스 문이 열리는 규칙과 피드백 확인.
4. 정글 1판의 먹이 경로·적 배치·동굴 입구 가독성 보완.
5. 일반 몹의 지면 접촉·스폰 위치·공격 예고 확인.

### P1 — 화면 생동감·스토리 전달

1. 나뭇잎, 나비, 덩굴 흔들림 등 환경 애니메이션.
2. 수우쿠렛 등장/실수/도망 시퀀스 적용(기존 대기작업 `232`와 연계).
3. 점수 팝업과 타격 시각 피드백 강화.
4. 상단에 작고 명료한 **누가 구출 표식** 추가.
5. 스테이지 전환 컷에서 킹콩과 누가의 관계 상기.

### P2 — 추가 실험 아이디어

1. 조건부 연속 처치 콤보 및 추가 점수 체계.
2. 킹콩의 실루엣을 이용한 특정 스테이지 전환 장면.
3. 정글 외 지역의 테마별 잔잔한 생태 연출.

> P2는 확정 기능이 아니며, 기존 Phaser 이전·검수 작업을 방해하지 않는 범위에서만 검토한다.

## 12. 화면 검수 체크리스트

- [ ] HUD의 시작 시간은 `60`으로 표시된다.
- [ ] FOOD는 최대 `60`을 넘지 않는다.
- [ ] 먹이 획득량 `+5 / +20 / +40`이 실제 게이지에 반영된다.
- [ ] FOOD가 가득 차기 전에는 보스 문이 열리지 않는다.
- [ ] 보스 체력은 보스 머리 위에만 나온다.
- [ ] 점수 획득 팝업이 나타날 때 플레이어를 가리지 않는다.
- [ ] 우가의 발과 발판이 맞닿고, 타격/피격이 식별된다.
- [ ] 사다리 시작·끝과 점프 착지점이 오브젝트로 막히지 않는다.
- [ ] 몬스터가 부자연스럽게 공중에서 생성되지 않는다.
- [ ] 수우쿠렛은 피해와 점수를 주지 않는다.
- [ ] 수우쿠렛은 달아난 뒤 같은 판에 다시 나타나지 않는다.
- [ ] 동굴 입구가 배경과 구분되고 진입 경로가 보인다.
- [ ] 환경 애니메이션이 공격 이펙트보다 눈에 띄지 않는다.
- [ ] 누가 구출 목적이 오프닝과 전환 연출에서 전달된다.
- [ ] 15판 기존 전용 패턴·안전 구역 규칙은 그대로 유지된다.

## 13. 최종 권고

> **UI를 더 많이 추가하는 것보다, 게임 세계 안에 ‘왜 이동하는지’, ‘무엇을 모아야 하는지’, ‘무엇을 피해야 하는지’를 보여주는 편이 효과적이다.**

이번 정글 화면에서는 **① 먹이 점프 경로, ② 작은 적과 공격 예고, ③ 동굴 주변의 의미 있는 흔적, ④ 수우쿠렛의 개그 행동, ⑤ 눈에 잘 보이는 FOOD·SCORE 피드백**의 다섯 가지부터 적용한다. 킹콩에게 납치된 누가를 구한다는 목적은 **오프닝 + 간결한 구출 표식 + 짧은 전환 컷**으로 유지한다.

### 확정 전 추가 결정이 필요한 항목

- 먹이 획득/일반 적 처치/콤보에 대한 **점수 공식**.
- 킹콩이 **실제 최종 보스인지**, 아니면 납치범으로만 등장하는지.
- 누가 구출 표식의 정확한 UI 형태와 표시 시점.

---

**문서 성격:** 기존 게임의 확정 사항을 유지하면서, 현재 화면을 실질적으로 개선하기 위한 별도 제안서. 원본 `우가누가_게임기획서.md`를 덮어쓰거나 기존 결정을 변경하지 않는다.
