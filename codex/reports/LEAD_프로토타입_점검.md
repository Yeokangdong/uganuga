# 프로토타입 점검

판정: **재작업**

2026-10-29 기준 `codex/DECISIONS.md` 전 항목을 `src/`, `public/assets/art.json`과 대조했다. `npm run build` 성공(TypeScript 검사 및 Vite 빌드, 종료 코드 0). 동작 판단은 코드 경로 분석이며 브라우저 실플레이 검증은 하지 않았다. 로고·플레이어 시트·HUD 참고 이미지는 직접 확인했다. 코드 수정 없음.

틀림 정도의 ‘작다’에는 일치 항목도 포함하며, 지금 상태에 **일치/미확인**을 명시한다.

## 구현 순서

1. 구현 담당 1명: 기존 동굴 원본을 배포용으로 연결하여 절벽·사다리·벽·바닥·입구를 완성한다(`level.ts`, `art.json`).
2. 구현 담당 1명: 동굴의 불 함정·거미·시계 그림을 등록하고, 불의 두 상태와 피해 범위를 일치시킨다(`entities.ts`, `art.json`).
3. 구현 담당 1명: 기존 UI 시트와 레이아웃으로 HUD 나무 틀·하트·초상 프레임을 연결한다(`GameHud.vue`, `art.json`).
4. 구현 담당 1명: 1P·2P 이동 표시를 걷기 프레임과 걷기 재생 속도로 맞춘다(`entities.ts`, `art.json`).
5. 구현 담당 1명: 타이틀 연출 중 첫 클릭도 STAGE 1 시작으로 이어지게 한다(`TitleScreen.vue`).
