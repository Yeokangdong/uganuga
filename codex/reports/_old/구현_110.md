# 구현 110
- 총 15판: 정글→화산→빙하와 기존 4~14판 순서를 유지하고 최종 새벽 정원을 15판에 배치.
- 판 번호에 따른 보스 HP·돌진 속도·탐험 난이도 증가를 유지하고 15판에만 final 지정.
- 15판 보스 처치→누가 공주 구출 연출(7초)→결과 화면으로 연결.
- 화면 하단 boss-meter와 관련 스타일 제거, 보스 머리 위 체력 게이지 유지.
- X/G 던지기 입력과 플레이어 던지기 동작·발사 경로 및 HUD 안내 제거.
- 기본 조작 안내: ←→·↑·Space, 2P A/D·W·F.
- 기존 그림 글자·숫자 로딩 복구, HUD·시작·결과·캔버스 문구를 공통 그림 렌더러로 교체.
- 전용 그림이 없는 문구는 구현_110_글자목록.md에 기록하고 기존 그림 조합을 임시 사용.
- npm run build 성공(vue-tsc 및 Vite); 실제 플레이 완주 검증은 수행하지 않음.
