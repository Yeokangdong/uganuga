# 맵 다듬기 1~5판 (151)
- 1판: 후반 수관을 넓은 층계로 정리하고 구간별 높이 차등화, 기존 막힘 우회 발판 유지.
- 2판: 밝은 뼈 구조물을 현무암으로 통일하고 후반 급경사 화산 단구 구성.
- 3판: 뼈 구조물을 얼음으로 통일하고 후반 넓고 완만한 빙하 선반 구성.
- 4판: 사암 지지물로 통일, 앞쪽 단구 간격 변화와 후반 메사형 층계 구성.
- 5판: 맹그로브 지지물로 통일, 앞쪽 상단 경로를 낮추고 후반 완만한 늪지 수관 구성.
- 공통: 1~5판 발판 원화의 투명 테두리를 제외해 보이는 양끝·상단과 판정을 정렬, 사다리 상단 1px 돌출 제거 및 4·5판 하단을 실제 지면에 맞춤.
- 검증: 사다리 105개 양끝·전체 794개 발판 렌더링 확인, 6~15판 데이터 동일·킹콩 오프닝 유지, npm run build 성공·Pages 배포 완료. 기존 현무암 받침 테스트는 테마 변경을 반영해 메모리에서 16번 재질로 대체 실행.
