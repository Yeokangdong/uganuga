# 채팅 직접 지시 — 표지판·이동 장치 전체 확인 (2026-11-02)

- 요청: 「모두 확인해」. 첨부된 빈 단풍 돌 표지판과 직전 공중 뗏목 문제를 포함해 현재 15판을 확인했다.
- 수정: 돌 표지판 번호를 캐시된 음각 그림으로 복구. 뗏목은 실제 연결된 수면에만 배치, 작은 수면 흔들림과 물 안쪽 물결만 표시. 나머지 이동 발판은 양쪽 실제 발판 높이에 지지선을 연결했다. 기존 원화·판 수·동선은 바꾸지 않았다.
- 검증: npm run build, node tools/check_signs_crossings.mjs (15개 번호 / 76개 이동 장치 / 수상 뗏목 3개), node tools/check_terrain_rendering.mjs (15판 발판 770구간 / 사다리 길이 80건 / 단차·구덩이 받침), node tools/check_caves.mjs 통과. tools/preview-visual-audit.html에서 실제 렌더러의 15판 표지판·이동 장치·지형 비교. 스크린샷: shots/visual-audit-final/.
