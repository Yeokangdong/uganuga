# 테스트 291 — 1~15판 화면 재점검

- 기준: main `79a1a3e`의 별도 임시 사본, Phaser 공개판. 작업 폴더의 진행 중 수정은 제외. 창 없는 Edge/Playwright.
- 결과 이미지: `shots/291_판별점검.png` — 15행×3열, 왼쪽부터 시작·중간·보스 문 앞, 2304×6840.
- 판별 좌표로 이동한 화면 검사이며 실제 완주가 아니다. 시작·중간은 20틱 갱신, 보스 앞은 수면을 피해 문 직전 고체 지면에 배치 후 렌더했다. 보스 전투·모든 구간·모든 애니메이션 프레임의 판정은 포함하지 않는다.
- 좌표는 월드 px. 아래 문제 좌표의 `약`은 화면으로 확인한 범위다. P2=눈에 띄는 시각 불일치, P3=경미한 마감 문제. 진행 차단 P1은 이번 장면에서 발견하지 못했다.

확인한 장면에서는 주인공·접지 몹의 명확한 부유, 몹의 지형 내부 생성, HUD 항목 간 겹침, 캐릭터 그림 잘림은 발견하지 못했다. 관측된 접지 몹은 발바닥과 충돌 바닥이 약 1px 이내였다. 수우쿠렛 배치 좌표는 바닥/수면 좌표와 일치했고 7·13판 매달림은 의도된 동작이다. 다만 수우쿠렛의 모든 동작 프레임과 화면 밖 개체는 미검증이다. 환경 이벤트의 단색 사각형은 `environment.ts`의 fillRect/strokeRect 렌더와 일치하며, 그림·충돌 불일치 자체를 확정한 것은 아니다.

검증: main 사본에서 `npm run build` 1회 성공(번들 크기 경고), 45장면 촬영 실행 중 pageerror 0. 게임 코드 수정·배포·다른 작업 큐 추가 없음.
