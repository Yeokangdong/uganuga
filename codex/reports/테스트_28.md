## 콘솔 오류

- `Failed to load resource: net::ERR_NETWORK_ACCESS_DENIED` — `https://fonts.googleapis.com/css2?family=Black+Han+Sans&family=Jua&display=swap`. 기본·stage2·stage3 각 1회, 총 3회. 환경의 네트워크 접근 제한으로 웹폰트 로딩 실패.
- `Failed to load resource: the server responded with a status of 404 (Not Found)` — `/favicon.ico`. 기본 화면 2회, stage2·stage3 각 1회, 총 4회. 별도 재확인에서 요청 URL 확인.
- 수집된 JavaScript `pageerror`: 없음.
