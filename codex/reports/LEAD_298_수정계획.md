## 결론과 점검 범위

예전 Canvas/Vue 엔진을 유지한다. A·B의 Phaser/Tiled 구현 예시는 구조 참고로만 사용한다. 최신 확정인 시간 60·TIME UP +20·시계 +10, 15판 킹콩, 미어캣 수우쿠렛을 우선 적용한다. A에 남은 ‘킹콩 최종 보스 미정’ 문구는 최신 결정으로 해소됐다. 취소된 경로 배너·말풍선·지역 이름표는 추가하지 않는다.

- main: `12a8986`, Vite `http://127.0.0.1:5298`, Chrome headless. 1~15판 직접 진입, 각 판 카메라를 180px 간격으로 보스 구역 앞까지 옮겨 생성·렌더 검사(각 32~37지점). 보스문 FOOD 59/60 및 보스 사망 분기는 런타임 상태 주입으로 검사했다. 추가로 TIME UP과 동굴 생성 수를 검사했다.
- Pages: `https://yeokangdong.github.io/uganuga/?stage=1`~`15`. 각 판 타이틀을 눌러 실제 공개 빌드의 HUD·첫 화면·콘솔을 검사했다. 공개 JS는 `assets/index-CnebS4CC.js`; 이번 main 빌드 결과 `index-DCvwfiXS.js`와 다르다. 로컬 `_pages` HEAD는 `2d3fc01`이나 공개 빌드와의 일치를 가정하지 않았다.
- 증거: `shots/298_점검.png`에 MAIN 15장과 PAGES 15장 합성. MAIN 하단의 개발용 판 선택기는 검사 UI이며 제품 HUD 오류가 아니다. Pages 1판은 진입 후 18초 대기한 화면(56), 나머지는 짧은 대기 화면(60)이다.
- **한계:** 키 입력만으로 15판 연속 완주한 검사가 아니다. Pages는 시작 화면 표본이며 중후반 지형·보스·시간 소진을 직접 검증하지 않았다. main 카메라 스캔도 모든 높이·애니메이션 프레임을 포괄하지 않는다. 상태 주입 통과를 FOOD 실제 수집 가능·동굴 왕복·공정한 전투·무막힘 완주의 증거로 쓰지 않는다.
