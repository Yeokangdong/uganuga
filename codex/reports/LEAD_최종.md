# 최종 점검 — 재작업

2026-10-29. `npm run build` 통과, `npm run preview -- --host 127.0.0.1`의 프로덕션 빌드를 Chrome headless 1280×720에서 실행했다. 코드·원화는 수정하지 않았다.

타이틀 진입은 실제 클릭으로 확인했다. 장면별 촬영은 브라우저 디버거로 기존 Game 인스턴스를 읽어 시간·위치·FOOD를 설정하고 기존 update/render를 호출했다. 후반 캡처는 정상 플레이 완주 증거가 아니다. 접촉·기절·고기·문 제한은 기존 메서드를 호출해 검사했다. 높은 주사율 실물 모니터와 전 구간 수동 완주는 미검증이다. 아래 ‘미확인’은 결함 확정과 구분한다. 뒤에 추가된 결정이 앞 결정보다 우선한다.

**FOOD 결론:** 세 판 모두 실제 막대는 보인다. 좌상단 HUD 아래, 도끼 오른쪽의 작은 나무 막대이며 1280 화면에서 영역은 약 128×26px이다. 빈 상태에서도 프레임 이미지는 정상 로드되고, 가득 차면 붉은 고기가 보인다. 다만 FOOD 글자·용도 안내가 없고 나무 패널 아래로 빠져 있어 식별성이 낮다. 화면 중앙의 초록/노랑 막대는 진행도이며 FOOD가 아니다. `check_food.jpg`의 문제를 ‘현재도 이미지 자체가 안 뜸’으로 단정할 수는 없다.

## 남은 일 순서 — 큰 것부터, 각 한 번의 구현 단위

1. 최종 스프라이트 로더 우선순위 수정: 주인공·일반몹·보스·거미를 8/4/6/2로 통일하고 동작별 누락 연결.
2. 보스 체력바 기준점 수정: 세 보스의 실제 그림 머리 위에 게이지·이름이 보이도록 배치하고 화면 경계 제한.
3. HUD 재배치: 점수·목숨·무기·FOOD를 나무틀 안에 넣고 FOOD 그림 라벨·충전 대비 확보.
4. 안내 그림 매핑 완성: 동굴·배고픔·꽝·느낌표·무기·시간 단위를 그림으로 표시.
5. 동굴 거미 배치 보장: 횃불 칸 충돌 시 재선택해 세 판 방마다 천장 거미를 확보.
6. 테마/명칭 정리: 1판 보스의 정글 배경 유지, 3판 보스 이름 그림·내부 이름을 공룡 외형과 통일.
7. 최종 로고의 도끼·고기 장식을 확정한 이름에 맞춰 보완.
8. 원본 시트 규격과 Samhan_Girls 그림체 대조: 사방15%·알파·셀 침범 포함, 참고 폴더에는 저장하지 않음.
9. 실플레이 검수 한 회: 2P·사다리·동굴 입출구·시계·사망 복귀·세 판 연속 진행·1판 초심자 난도, 60/120/144Hz 비교.
