# 306 키 입력 완주 검사기

- 신규: `tools/playthrough.mjs`. `src/`·art-src 수정 없음.
- 사용: `node tools/playthrough.mjs --stages 1-15 --out shots/playthrough`
- Playwright 필요. 기본 headless Edge(Chromium), `CHROME_PATH`로 Chrome 지정 가능. `PLAYWRIGHT_MODULE` 지원.
- npm run dev를 5306/strictPort로 실행하고 종료 시 해당 서버·브라우저 프로세스 트리 정리. 게임 상태는 기존 개발용 `window.__game`에서 읽기만 하고 ← → ↑ Space만 입력. 시간 가속·좌표/체력/먹이 변경·엔진 메서드 호출 없음.
- 먹이·적 접근, 장애물 점프, 보스 근접 공격 정책. FOOD 60 → 보스전 → 처치 후 연출 → 다음 판(15판은 clear) 관측을 모두 충족해야 O.
- 판마다 URL로 독립 시작. 연속 15판 생존 검사는 아님. 정체 22초, 판당 실제 시간 240초 제한(Codex 판단). `--timeout 초`로 제한 변경 가능. 시작 로딩·스크린샷 시간은 별도라 총 소요 시간은 제한을 넘을 수 있음.

## 현재 상태 1~3판 시험

| 판 | 완주 O/X | 막힌 곳 | 걸린 시간(실제) |
|---|---|---|---|

| 2 | X | FOOD 60, 보스 진입 전 목숨 소진 · (5867.58, 329.50) · 게임 98.41초 | 226.91초 |

- 페이지 실행 오류: 세 판 모두 0. 보스 처치·다음 판 전환은 이번 시험에서 미검증. 이 자동 입력 정책의 실패이며 게임 자체의 완주 불가능 판정은 아님.
- 증거: `shots/playthrough/results.json`(판·좌표·게임/실제 시간·진행 이벤트·마지막 상태), `stage-01-1793763190155.png`, `stage-02-1793763417005.png`, `stage-03-1793763626049.png`(같은 폴더). 존재·크기 확인.
- 검증: npm run build 1회 성공, node --check 성공. 최초 시험 후 종료 지연을 보완하고 `--stages 1 --timeout 1 --out shots/playthrough/lifecycle`로 npm 서버 시작·시간 제한·스크린샷·프로세스 종료 재확인(포트 5306 해제). 이 짧은 시험은 완주 결과 표에서 제외.
- 결과 파일은 `--out` 아래에 저장, 실패 시 종료 코드 1 / 전 판 성공 시 0. 기존 스크린샷은 유지하며 results.json은 해당 실행 요약으로 갱신.
- 다음: 입력 정책의 적 회피·전투/경로 개선 후 보스전과 다음 판 전환 실증.
