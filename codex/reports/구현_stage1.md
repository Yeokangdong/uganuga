# 스테이지 1 통과 확인

- 막힌 곳: 없음. 지형 수정 없음(그림·다른 스테이지 포함).
- JUMP_VEL 350, GRAVITY 900, 타일 16, 이동 속도 80 기준. 점프 최고 높이는 이론상 68.1px, 60fps 계산상 약 65.2px이며 점프 버튼을 유지해야 한다.
- 실제 moveBody 충돌 함수와 사다리 판정을 적용한 메모리 내 이동 탐색으로 START부터 ARENA(280열, x=4480) 및 내부 x=4801까지 도달 확인. 적 전투·보스 처치는 검증 범위 밖이다.
- 절벽은 왼쪽 낮은 바위와 계단을 거쳐 오르고, 반전 절벽은 진입 사다리를 이용한다. 반전 절벽의 64px 단차도 통과 가능하다.
- 탑은 왼쪽 48px 높이 발판을 밟고 지붕으로 32px 점프하면 통과한다. 구덩이와 다리도 발판 경유로 통과한다.
- 검증: npm run build 통과.
