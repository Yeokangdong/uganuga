# 대표가 Codex에 직접 지시할 때 (실장이 알 수 있게)

실장(Claude)은 `D:\99.Work\Uganuga\codex` 폴더의 파일과 git 기록만 봅니다.
Codex 앱 채팅창에서 한 대화는 실장이 볼 수 없습니다.
아래 방법 중 **하나만** 지키면 됩니다.

## 방법 1 (가장 좋음) — 작업 파일로 넣기

1. 메모장으로 새 파일을 만들어 `D:\99.Work\Uganuga\codex\queue\` 에 저장합니다.
   - 파일 이름: `번호_대표_내용.txt` (예: `200_대표_점프높이.txt`)
   - 번호는 마지막 작업 번호보다 크게 (done 폴더에서 확인)
2. 내용은 하고 싶은 말 그대로 적으면 됩니다. 예:
   ```
   [구현] 점프를 조금 더 높게. 파일 삭제 금지.
   결과: codex\reports\구현_200.md 3줄.
   ```
3. 작업 관리자가 자동으로 Codex에 넘기고, 로그·보고서가 남아 실장이 바로 확인합니다.

## 방법 2 — Codex 앱에서 직접 시킬 때

Codex 앱 채팅으로 시켰다면, 지시 끝에 이 두 줄을 붙여 주세요.

```
끝나면 codex\DECISIONS.md 맨 아래에 "- 날짜 | 사용자: 「내가 한 말」 | 한 일 요약" 한 줄 추가.
그리고 git add -A; git commit -m "한 일 요약"; git push origin main 실행.
```

- DECISIONS.md 한 줄 → 실장이 **무엇을 왜 바꿨는지** 압니다.
- git 커밋 → 실장이 **어떤 파일이 바뀌었는지** 압니다.

## 방법 3 — 그냥 실장한테 말하기

Claude 대화창에 "Codex로 ○○ 바꿨다" 한 줄만 남겨도 됩니다.
