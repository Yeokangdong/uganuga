## 2) 정보창(UI) — **기준 디자인: `D:\99.Work\ugauga\codex\ref\hud_mockup.png`** (반드시 참조 이미지로 넣을 것)
기준 그림과 같은 느낌으로, 글자·숫자·얼굴·하트를 **뺀 빈 부품**만 그린다 (글자·숫자는 게임이 직접 씀).
`art-src\ui\ui_sheet.png` (1536×1024, 투명) 에 아래 부품을 넉넉한 간격으로 배치:
- `panel` : 가로로 긴 나무 틀 정보창 (기준 그림처럼 굵은 나무 테두리, 모서리 덩굴·잎, 왼쪽에 얼굴이 들어갈 둥근 나무 액자 칸, 안쪽은 어두운 갈색 반투명 판) — 가로:세로 약 3.4:1, **안쪽 비어 있음**
- `portrait_frame` : 얼굴 액자만 따로 (둥근 나무 틀, 가운데 투명)
- `heart_full` : 빨간 하트 (기준 그림 하트처럼, 진한 외곽선)
- `heart_empty` : 빈 하트 (어두운 갈색)
- `life_uga`, `life_buga` : 목숨 표시용 작은 얼굴 (우가 주황머리, 부가 보라머리)
- `w_axe`, `w_bone`, `w_fire` : 무기 아이콘 (돌도끼 · 뼈 몽둥이 · 횃불 도끼)
- `tag` : "1P" 글자가 들어갈 작은 주황 돌 명패 (글자 없이)
- `timer` : 둥근 돌 원판 (타이머 배경, 가운데 비어 있음)
- `boss_frame` : 뼈로 만든 가로 막대 틀 (보스 체력바, 가운데 빈 홈)
- `scroll` : 가죽 두루마리 (일시정지·결과 창 배경)
- `button` : 가로로 긴 나무 판자 버튼
