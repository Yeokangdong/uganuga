# 대표 결정 (게임 내용만, 원본: 실장 수신함)

- 고인돌1·2(Joe & Mac) 같은 횡스크롤 액션. Vue3 + TypeScript, 폴더 D:\99.Work\ugauga
- 조작: ← → 이동, ↑ 점프, 스페이스 공격 (2P: A D / W / F). 캐릭터는 걷는다(달리지 않음)
- 공격은 던지기가 아니라 돌도끼를 들고 때리기
- 보스 체력 게이지는 보스 머리 위. 타이머 있음(시계 아이템 = 시간 추가)
- 시작화면: 원화 + 거대한 타이틀 팍 박힘(돌도끼·고기 섞인 글자, "우가우가"로 읽혀야), 아래 "클릭 시 시작", 시작하면 "STAGE 1"
- 스테이지 3개: 정글 → 화산 → 빙하. 보스·일반 몬스터 스테이지마다 다름
- 지형: 슈퍼마리오식 평지 X. 층층 바위 절벽·사다리·동굴 (참고 그림: 고인돌 스타일)
- 동굴: 들어가면 짧은 동굴 방, 어두컴컴. 결과 다양(시계 / 고기 / 꽝 / 몬스터 …). 천장 거미(오르내림, 닿으면 체력−), 바닥 횃불(점프로 피함, 닿으면 체력−)
- 정보창 UI는 원시적으로 — codex\ref\hud_mockup.png (나무 틀·얼굴·1P·이름·점수·하트·목숨×3·무기)
- 그림체: Samhan_Girls 그림체 참고(폴더에 아무것도 저장 금지)
- 화면에 연도 표시 금지
