# 우가누가! — 맵 긴장감 강화 기획안

> 작성일: 2026-11-03  
> 대상: Phaser 3 + Tiled 기반 2D 횡스크롤 액션 게임  
> 목적: 15개 스테이지에서 **탐험 → 불안 → 위기 → 안도 → 보스전**의 리듬을 만들고, 누가 구출이라는 목표를 플레이 내내 체감하도록 한다.

## 0. 적용 기준: 기존 확정 사항과 신규 제안 구분

**[기존 기획 확정 — 유지]**
- 원시인 **우가**가 킹콩에게 납치된 **누가**를 구출하는 1인용 액션 게임. 15판과 최종 보스, 구출 엔딩.
- 조작: 좌/우 이동, 위 점프(사다리 앞에서 오르기), Space 공격. **던지기 없음**.
- 판 시간 표시는 **60**부터 시작하며, 0이 되면 `TIME UP` 이후 20 추가. 시계 아이템은 +10. 시간 표시 1칸은 실제 약 3.6초.
- FOOD 최대 60. 먹이 아이템(+5/+20/+40)으로 채우며, **FOOD가 가득 차야 보스 문이 열림**.
- 동굴은 보너스 공간이며 스테이지별 입구 위치가 다름. 목숨 추가 및 부활점/부활 불꽃 연출.
- 클리어 시간 보너스: 남은 시간 × 10점. 보스 체력은 **보스 머리 위**에만 표시.
- 15개 판의 **전용 등장체와 전용 위험 동작**은 변경하지 않는다.
- 모든 위협은 **사전 예고**를 제공. 화면 밖 기습 금지. 시작점, 부활점, 사다리 출입구, 필수 착지점은 안전하게 유지.
- 맵은 판마다 다른 형태(3층까지), 자연스럽게 연결된 지형. 그림과 충돌 판정 일치.
- **수우쿠렛**은 점수/피해 없는 순수 개그 캐릭터. 판마다 1~2마리 초기 배치, 근접 시 놀라 도망가고 재등장하지 않음.

**[신규 제안 — 승인 후 구현]**
- 각 스테이지에 **환경 변화 이벤트 1종**을 추가한다. 기존 전용 몬스터 패턴을 **교체하지 않고 보완**한다.
- 추격, 지형 붕괴, 수위/용암 상승 등은 **짧고 명확한 연출 구간**에서만 사용한다.
- 킹콩과 누가의 실루엣·발자국·흔적 등으로 구출 동기를 강화한다.
- 아래의 수치·위치·구간 비율은 **초기 권장값**으로 실제 테스트 후 조정한다.

## 1. 핵심 설계 원칙

1. **위험을 미리 보여주고 나중에 실행한다.** 흔들림·균열·먼지·표식·소리 등으로 회피 가능성을 명확히 한다.
2. **단조로운 연속 전투를 피한다.** 평온한 수집 구간과 짧은 위기 구간을 번갈아 배치한다.
3. **화면 안의 원인으로 위험을 설명한다.** 나무가 흔들려 쓰러지고, 절벽의 자갈이 먼저 떨어진 뒤 낙석이 떨어진다.
4. **도전은 어렵더라도 실패 이유는 분명하게 한다.** 플레이어가 위험의 방향·발생 시간을 읽을 수 있어야 한다.
5. **필수 진행을 막지 않는다.** FOOD 60 확보, 보스 문 진입, 동굴 진입, 복귀 경로가 이벤트 때문에 불가능해져선 안 된다.
6. **한 판에 핵심 이벤트를 과적재하지 않는다.** 지형 이벤트는 우선 한 종류만 도입한다.
7. **1판은 배우기 쉬워야 한다.** 15판으로 갈수록 위험 조합과 리듬을 조금씩 복잡하게 한다.

## 2. 스테이지 긴장도 리듬

| 스테이지 진행률(권장) | 긴장도 | 주요 플레이 | 연출 |
|---|---|---|---|
| 0~20% | 낮음 | 이동 학습, 먹이 수집, 지형 관찰 | 밝은 BGM, 배경 생물 움직임 |
| 20~40% | 보통 | 기존 전용 등장체·일반 몬스터 | 위험 예고·회피 학습 |
| 40~60% | 높음 | **신규 환경 이벤트** | 화면 떨림·음악 변화·짧은 추격 |
| 60~80% | 낮음 | 동굴·보너스·FOOD 보충·안전 구간 | BGM 완화, 숨 돌릴 공간 |
| 80~100% | 매우 높음 | 보스 문 접근 및 보스전 | 포효·배경 연출·보스 진입 효과 |

> 구간 비율은 **맵 길이 또는 플레이어의 진행 경로**를 기준으로 적용한다. 실제 판에 따라 동굴·보스 구역의 위치를 우선한다. 진행률별 배치는 확정 규칙이 아닌 가이드다.

### 이벤트 발생 흐름

`발견(배경 암시) → 예고(화면·소리) → 위험 발생 → 회피/탈출 → 정리 → 휴식`

- 처음에는 낮은 위험의 예시를 안전한 장소에서 한 번 경험시킨다.
- 플레이어가 위험을 인지할 수 있는 시점부터 카운트다운을 시작한다.
- 실패해도 무엇을 해야 했는지 이해할 수 있도록 동일한 전조를 재현한다.
- 이벤트 종료 후 보상 먹이나 넓은 안전 지대를 배치해 리듬을 끊어 준다.

## 3. 스테이지별 환경 이벤트 제안 (15개)

> 아래 '기존 고유 패턴'은 원본 기획을 요약한 것이며, '추가 환경 이벤트'는 새 제안이다. 두 시스템은 같은 장소에서 동시에 과밀하게 발동하지 않도록 한다.

| 판 | 지역 | 기존 고유 패턴 (유지) | 추가 환경 이벤트 (제안) | 예고 / 플레이 방식 |
|---:|---|---|---|---|
| 1 | 원시 정글 | 매달린 원숭이의 코코넛 투척 | **쓰러지는 나무** | 잎·나뭇가지 흔들림 → 나무 기울어짐 → 점프로 통과 |
| 2 | 불타는 화산 | 용암 방울 정령의 포물선 낙하 | **서서히 상승하는 용암** | 용암 기포·경고음 → 한정 구간 수직 탈출 |
| 3 | 얼어붙은 빙하 | 얼음 쐐기 정령의 얼음창 | **깨지는 얼음 발판** | 균열→금 확대→붕괴 전 이동 |
| 4 | 황금 모래사막 | 모래 개미귀신의 솟아오르는 턱 | **모래폭풍·모래에 잠기는 길** | 먼지·바람 선행 → 짧게 시야 흐림, 높은 길 선택 |
| 5 | 안개 늪지 | 늪 거머리의 혀 공격 | **가라앉는 통나무** | 발판 침하 예고 → 다음 발판으로 이동 |
| 6 | 대나무 숲 | 대숲 매미의 고리 음파 | **휘어지는 대나무 발판** | 탄성 예고 → 점프 타이밍 활용 |
| 7 | 붉은 협곡 | 절벽 돌굴림 정령의 튀는 돌 | **거대 바위 추격** | 먼지·낙석·진동 → 짧은 좌→우 탈출 |
| 8 | 수정 계곡 | 수정 굴절 정령의 사선 광선 | **균열 난 수정기둥 붕괴** | 밝아지는 금 → 낙하 예상 구역 피하기 |
| 9 | 노을 해안 | 파도 말미잘의 낮은 파도 | **대형 파도 밀려옴** | 바닷물 후퇴·거품 → 높은 발판으로 이동 |
| 10 | 달빛 버섯 숲 | 포자 등불 정령의 포자막 | **포자 안개** | 버섯 발광 → 일부 구역 일시적 시야 제한 |
| 11 | 고대 돌기둥 유적 | 문양 석면의 부채꼴 석화 시야 | **돌기둥 연쇄 붕괴** | 돌가루·균열→ 지정 구간 피하기 |
| 12 | 천둥 고원 | 피뢰석 정령의 순차 낙뢰 | **낙뢰로 파손되는 발판** | 전기 예고표시→발판 균열→대체 경로 이동 |
| 13 | 거대한 폭포 | 폭포 물뱀의 S자 이동 | **수위 상승·급류** | 수면 상승 표시→높은 곳으로 피신 |
| 14 | 가을 단풍 숲 | 단풍 잎거미의 진자 왕복 | **흔들리는 나뭇가지 낙하** | 가지 꺾이는 소리→낙하 위치 피하기 |
| 15 | 오로라 설원 | 눈조각사의 눈 고리·서리 기둥 | **눈사태 추격** | 눈가루·굉음→장애물 사이 긴급 이동 |

### 동시발동 제한

- 기존 고유 패턴과 신규 환경 이벤트가 **반드시 같은 프레임에 겹칠 필요는 없다**.
- 신규 환경 이벤트 구간에서는 기존 패턴의 발동을 일시 중지하거나 간격을 늘린다.
- 원본의 고유 패턴 반복 간격 기준(1~5판 6초 이상 / 6~10판 5초 이상 / 11~15판 4초 이상)은 유지한다.
- 플레이어가 접근하기 전에 화면 밖에서 낙하·돌진·붕괴를 시작하지 않는다.

## 4. 대표 이벤트 상세 예시

### 4.1. 1판: 쓰러지는 나무 (입문형)

**목적:** 위험 예고를 읽고 짧게 회피하는 방법을 학습.

1. 우가가 평온하게 먹이를 모은다. 수우쿠렛이 애벌레를 따라 뛰어가다 넘어지는 개그 연출.
2. 멀리 나무가 살짝 흔들리고 낙엽이 떨어진다.
3. 나무가 기울어지는 방향이 명확히 보이고 짧은 사운드가 난다.
4. 나무가 **화면 안**에서 넘어지며 작은 장애물이 된다.
5. 플레이어는 점프해 넘어간다. 이후 안전한 먹이·휴식 구간으로 연결한다.

**안전 조건:** 나무가 필수 먹이, 동굴 입구, 사다리 출입구를 영구적으로 막지 않음. 첫 시도에 실패해도 복구·재도전 가능.

### 4.2. 7판: 굴러오는 거대 바위 (추격형)

**목적:** 평소 탐험과 다른 속도감 있는 긴급 탈출.

1. 협곡에 자잘한 돌이 떨어지고 멀리 진동이 느껴진다.
2. 화면 안 좌측에서 거대 바위가 등장한다.
3. 우가는 우측으로 달리며 낮은 장애물을 점프로 넘는다.
4. 추격 속도는 우가의 정상 이동 속도를 고려해 **재현 가능한 난이도**로 조정한다.
5. 안전한 통로 끝에 도달하면 바위가 지형에 부딪히고 멈춘다.
6. BGM이 안정되고 FOOD 보충 구간으로 이어진다.

**금지:** 이벤트 시작 직후 피할 수 없는 접촉, 사다리 강제 사용 중 추격, 화면 밖 즉시 충돌, 실패 시 영구 통로 봉쇄.

### 4.3. 13판: 수위 상승 (판단형)

**목적:** 지형을 읽고 높은 곳으로 이동하는 플레이.

1. 폭포 소리가 커지고 물결 표시가 상승한다.
2. 안전한 높은 발판이 카메라 안에 명확히 보인다.
3. 낮은 구간부터 물이 차오른다.
4. 우가는 보이는 안전 경로를 따라 위로 이동한다.
5. 일정 지점에 도달하면 물이 빠지거나 이벤트가 종료된다.

**안전 조건:** 수위가 필수 먹이 획득이나 보스 문 진입을 불가능하게 만들지 않는다.

## 5. 킹콩·누가 구출 서사를 맵에 녹이는 방법

### 기본 원칙

- 킹콩은 **최종 보스 역할**을 유지한다. 중간 등장 시에는 무조건 전투하지 않고 배경 연출만 가능.
- 누가의 흔적은 길 찾기·목표 상기용으로 사용한다. 필수 아이템이나 점수 규칙을 임의로 변경하지 않는다.

### 사용 가능한 연출

| 시점 | 화면 연출 | 효과 |
|---|---|---|
| 오프닝 | 킹콩이 누가를 데리고 납치 | 주요 목표 명확화 (기존 확정) |
| 중간 스테이지 | 멀리 보이는 킹콩의 거대한 실루엣 | 다음 지역을 향한 추격 동기 |
| 동굴 근처 | 킹콩의 거대한 발자국, 부서진 나무 | 지나간 흔적 전달 |
| 긴장 구간 직전 | 새 떼가 날아가거나 땅이 미세하게 흔들림 | 사건이 다가옴을 암시 |
| 후반 스테이지 | 누가가 떨어뜨린 리본·장식(시각 연출) | 구출 목표 재확인 |
| 최종 판 | 킹콩·누가와 대면, 최종 전투 후 구출 | 이야기 완결 (기존 엔딩 유지) |

**선택 연출:** 특정 스테이지 끝에서 킹콩이 누가를 데리고 다음 지역으로 이동하는 장면을 짧게 보여준다. 장면이 플레이 흐름을 지나치게 끊지 않도록 한다.

## 6. 화면·사운드 연출 명세

| 요소 | 평상시 | 위험 예고 | 위기 발생 | 종료 |
|---|---|---|---|---|
| BGM | 지역 기본곡 | 낮은 경고음·리듬 변화 | 짧은 추격 테마 | 자연스럽게 복귀 |
| 카메라 | 정상 추적 | 미세한 진동 (선택) | 짧은 흔들림 | 흔들림 종료 |
| 지형 | 정상 | 균열·흔들림·먼지·물결 | 붕괴·상승·추격 | 안정 상태 |
| 적 | 일반 행동 | 필요 시 공격 간격 조정 | 이벤트와 충돌하지 않도록 제한 | 원래 상태 복귀 |
| UI | 기존 HUD | 식별 가능한 위험 표시 | 진행을 방해하지 않는 최소 표시 | 기존 HUD 유지 |

- 강한 화면 흔들림은 **짧게**, 빈번한 번쩍임은 최소화한다.
- 화면 가림 효과가 적, 발판, 필수 착지점, 우가의 위치를 숨기지 않게 한다.
- **접근성 옵션**으로 화면 흔들림·번쩍임 효과를 줄이거나 끌 수 있게 하면 좋다(신규 제안).
- 점수·FOOD·시간 등 기존 HUD의 의미를 바꾸지 않는다.

## 7. Phaser 3 + Tiled 구현 방향 (개발 지침)

### Tiled 레이어 구성 예시

- `Ground` — 지형 및 충돌 타일
- `Platforms` — 발판/사다리
- `DecorBack` / `DecorFront` — 배경·전경 장식
- `Enemies` — 기존 등장체 배치 오브젝트
- `EventTriggers` — 이벤트 진입 영역(사각형 객체)
- `EventActors` — 쓰러지는 나무, 바위, 수위 오브젝트 등의 초기 위치
- `SafeZones` — 시작점, 부활점, 사다리 출입구, 필수 착지점
- `FoodSpawns` — 필수 먹이 배치 검증용

> 실제 프로젝트의 레이어 이름과 구조는 기존 소스를 우선한다. 위 목록은 **추가 설계 제안**이며 기존 데이터 구조를 무조건 교체하라는 지시가 아니다.

### 권장 이벤트 상태 머신

`IDLE → TELEGRAPH → ACTIVE → RESOLVED`  
필요 시 `CANCELLED`(플레이어 사망·장면 전환) 포함.

- **IDLE:** 플레이어가 진입할 때까지 대기. 이벤트 오브젝트는 시작부터 맵에 배치돼 있어야 함.
- **TELEGRAPH:** 위험을 알리는 애니메이션·효과음. 이 상태에서 플레이어가 안전 경로를 인지할 수 있어야 함.
- **ACTIVE:** 실제 충돌/위험 판정 활성화.
- **RESOLVED:** 추격 정지, 지형 안정화, 통과 보장. 이벤트 재진입 여부는 판별 설계.
- **CANCELLED:** 부활·재시작 시 타이머, 애니메이션, 콜라이더, 카메라 효과를 정리.

### 구현 시 주의 사항

1. 이벤트 영역 진입은 **한 번만** 발동하도록 관리한다(반복 이벤트일 경우 명시적으로 리셋).
2. 카메라의 현재 표시 영역과 실제 충돌 활성 영역을 검증한다.
3. 고정 타이머만으로 플레이어가 화면 밖에 있을 때 공격을 시작하지 않는다.
4. 속도·예고 시간은 상수/데이터로 분리한다. 난이도 조정 시 코드 수정 최소화.
5. 추격 중 실패하면 부활점에서 **정상 상태로 복원**한다.
6. 시작점·부활점·사다리·필수 착지점은 위험 판정에서 제외하거나 충분히 보호한다.
7. `FOOD=60` 달성에 필요한 먹이를 이벤트 이후에도 얻을 수 있는지 통합 테스트한다.
8. 기존 15판 전용 패턴의 생성·반복·회피 구조를 손상하지 않는다.
9. 수우쿠렛은 환경 이벤트 중에도 피해·점수 없이 코믹한 반응만 하도록 유지한다.

## 9. 필수 QA 체크리스트

- [ ] 위험이 실제 발생하기 전에 **시각 또는 소리로 예고**되는가?
- [ ] 위험의 방향과 회피할 안전 공간이 **카메라 안**에 보이는가?
- [ ] 시작점·부활점·사다리 출입구·필수 착지점이 보호되는가?
- [ ] 추격이나 붕괴 이벤트가 영구 진행 불능을 만들지 않는가?
- [ ] 모든 스테이지에서 FOOD를 60까지 채우고 보스 문을 열 수 있는가?
- [ ] 시간 60, TIME UP 후 20 추가, 시계 +10 등 **기존 규칙**이 정상 동작하는가?
- [ ] 원본 15판 고유 패턴이 남아 있으며 공정한 회피가 가능한가?
- [ ] 동굴·보너스 공간 진입이 정상인가?
- [ ] 플레이어 사망/부활/재시작 시 이벤트 오브젝트가 초기화되는가?
- [ ] 카메라 흔들림·안개·이펙트가 우가 또는 발판을 가리지 않는가?

## 10. 최종 권고

**'적을 더 많이 놓는 것'보다 '맵이 사건을 일으키도록 만드는 것'이 우가누가의 긴장감을 높이는 방향이다.**  
먼저 **1판 나무 붕괴 → 7판 바위 추격 → 13판 수위 상승**의 세 가지 서로 다른 유형을 검증하고, 플레이가 재미있고 공정하게 느껴질 때 나머지 12판으로 확장한다.  
항상 **기존 기획의 시간·FOOD·15판 고유 패턴·수우쿠렛 규칙을 유지**하면서 추가 이벤트를 검토한다.
