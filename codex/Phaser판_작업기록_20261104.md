## 3. Phaser판에 넣은 기능 (되돌리면 함께 빠짐)

### 규칙
- **게임 시간 60**: 모든 판, 1판 2배 없앰. TIME UP 후 +20. 시계 +10. (233)
- **점수 임시값(Claude 판단)**: 먹이 +5=50 / +20=200 / +40=400, 일반 몹 100, 보스 5000. (235)

### 캐릭터·그림
- **주인공 우가 Ludo 동작**: 걷기 20장, 공격(0~8장 사용), 점프(머리 잘린 장 제외), 사다리 오르기(그림 속 사다리 제거). (224)
- **몬스터 표정 완화**: 조금 순하게, 원본 유지하고 `_soft` 사본. (230)
- **수우쿠렛(미어캣)**: 판마다 1~2마리 처음부터 배치. 다가오면 놀라 도망가고 다시 안 나옴. 판별 반응(용암·얼음·물·낭떠러지). 피해·점수 없음. 기존 다람쥐 그림은 영화 캐릭터와 닮아 미사용. (232)
- **15판 최종 보스 킹콩**: 패턴 3개(가슴 두드리기 충격파 / 돌진→벽 충돌 어지러움 / 뛰어 내려찍기), 체력 절반 이하 분노. 처치 후 누가 구출. (236)
- **킹콩 Ludo 그림 교체**: (289) — 구현됐으나 검수 수정 중이었음.

### 화면 개선안 (`codex\우가누가_게임기획_화면개선안.md`)
- **P0 (234)**: HUD 정리, FOOD 35/60 숫자+게이지, FOOD FULL! 연출과 보스 문 열림 동기화, 정글 1판 먹이 경로·첫 적·동굴 흔적, 몹 지면 접촉.
- **P1 (235)**: 환경 움직임(나뭇잎·나비·덩굴), 점수 팝업, 타격감(멈칫·흔들림·별), 누가 구출 표식, 판 시작·클리어 짧은 컷.

### 맵 긴장감 기획안 (`codex\우가누가_맵_긴장감_강화_기획안.md`)
- **P0 (237)**: 환경 이벤트 공통 상태 머신(IDLE→TELEGRAPH→ACTIVE→RESOLVED/CANCELLED), 1판 쓰러지는 나무, 15판 회귀 테스트.

## 4. Ludo로 만든 그림 (`codex\inbox\`, 엔진과 무관하게 재사용 가능)

| 파일 | 내용 |
|---|---|
| `uga_walk_ludo` | 우가 걷기 20장 |
| `uga_attack_ludo` | 우가 공격 25장(앞 9장 사용 권장) |
| `uga_jump_ludo` | 우가 점프 25장(8~11장 머리 잘림) |
| `uga_ladder_ludo_v1`, `_v2` | 우가 사다리 오르기(그림에 사다리 포함, v2 권장) |
| `suukuret_*` 9종 | 미어캣: idle·flee·lunge·swim·dangle·burn·freeze·slip·hug |
| `kingkong_*` 5종 | 킹콩: pound·charge·dizzy·slam·defeat |
| 기본 그림(Ludo 계정에만 있음) | 정글 나무 2종, 거대 바위 2종, 킹콩 2종 |
| 나무 쓰러짐 | Ludo 계정에 생성 완료, 아직 못 받음 |

- 모든 시트는 png + 같은 이름 json(Phaser 아틀라스 형식, 대부분 6×6=36장).
- 화풍 기준: 우가 걷기 첫 장을 Ludo "Reference Image"로 사용.
- **아직 못 만든 그림(Ludo 크레딧 소진)**: 바위 굴림·충돌 먼지, 수위 물결, 새 떼, 판별 이벤트 그림 8종.

## 5. 이번에 정한 결정 (DECISIONS.md에도 기록)

- 15판 최종 보스는 킹콩이다.
- 작은 동물 이름은 **수우쿠렛**이다. 길고 마른 미어캣이고, 이름만 오마주한 원작 디자인이다.
- 움직임이 많은 그림은 Ludo로 만든다. Codex는 임시 구현을 하고 "Ludo 요청" 표를 쓴다.
- 경로 배너·말풍선·지역 이름표(241~243)는 대표가 취소했다.

## 6. 작업 관리자 변경 (`codex\dispatcher.ps1`)

- **v4**: 끝났는데 running에 남은 작업을 자동으로 정리한다(로그에 tokens used가 찍히고 10분 넘게 변화가 없거나, 90분 무응답).
- **취소 작업**: 첫 줄이 `[취소]`인 작업은 실행하지 않고 `_old\cancelled`로 옮긴다.
- **멈춤 장치**: `codex\HOLD.txt`가 있으면 자동 체인을 멈추고, 이름에 `_긴급_`이 있는 작업만 실행한다. 재시작한 뒤부터 적용된다.
