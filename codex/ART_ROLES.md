# 원화팀 일 나누기

한 작업에는 한 담당만. 지시서 이름 앞에 담당을 붙인다 (예: 20_캐릭터_xxx.txt).

| 담당 | 맡는 그림 |
|---|---|
| 캐릭터 | 주인공(우가·부가)·일반 몬스터·보스 시트, 공격·걷기·점프 동작 |
| 배경 | 스테이지 배경 레이어, 지형 타일, 동굴 방 배경, 소품 |
| UI·이펙트 | 정보창 부품, 타이틀 로고, 아이템 아이콘, 타격·충격파 이펙트, 함정(거미·횃불) |

- 같은 담당 일은 이어서 하고, 다른 담당 일은 동시에 돌릴 수 있다.
- 결과는 Codex 팀장이 1차 검수한다 (TEAM_LEAD.md).
