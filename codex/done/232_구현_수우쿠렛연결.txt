[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만들고 기존 결과물은 재생성하지 않는다. 검증용 스크립트·보고서·메모를 따로 만들지 않으며 저장은 존재·크기만 확인한다.
- 필요한 문서·항목만 읽고 참고 이미지는 필수 1~2장만 사용한다. 질문 없이 끝까지 진행하고 설명은 짧게, 완료 시 결과 파일 목록 한 줄만 출력한다.
- 스프라이트는 칸마다 사방 15% 이상 여백, 칸 밖·옆 칸 침범 금지, 실제 투명 배경을 지킨다.
- 긴 소스·로그는 검색 후 필요한 범위만 읽고, 이미 읽은 내용·전체 목록을 반복 출력하지 않는다.
- 빌드는 완료 확인에 1회 실행하고 이후 변경·실패가 있을 때만 재실행한다. 이미지 생성·열기는 필요한 대상만 처리한다.
- 정기 토큰 점검은 매 10번째 작업마다 1회만: 로그 끝 tokens used 상위 10개와 원인 확인·규칙 보완(이번은 141번 특별 점검).

공통: git 브랜치 phaser, 새 코드는 src-phaser\. 기존 src\·public\assets 원본 수정·삭제 금지, main·gh-pages 건드리지 말 것. 창 띄우지 말 것. .bat 금지. 다른 작업 큐에 넣지 말 것. 토큰 절약.
그림: codex\inbox\suukuret_*.png + 같은 이름 .json (Phaser 아틀라스, 각 36장). 동작: idle(두리번)·flee(놀라 도망)·lunge(애벌레 덮치다 꽈당)·swim(물속 볼빵빵 헤엄)·dangle(이빨로 바위 매달림, 바위 조각이 그림에 포함)·burn(엉덩이 데여 펄쩍)·freeze(꽁꽁→얼음 깨짐)·slip(얼음 미끄러져 빙글)·hug(애벌레 껴안다 숨기기). src-phaser 에셋 폴더로 복사해 쓰기.
기존 다람쥐(public\assets\painted-v6\squirrel-*.webp, title-scrat-acorn-offer.webp)는 Phaser 판에서 쓰지 말고 수우쿠렛으로 대체. scrat 이름 쓰지 말 것.
규칙: 판마다 1~2마리가 처음부터 맵에 놓여 있음(갑자기 생기지 않음). 평소 idle/hug 반복, 가끔 애벌레 쫓아 lunge. 주인공이 일정 거리(약 3타일) 안에 오면 flee로 화면 밖까지 도망 후 사라짐(그 판에서 다시 안 나옴). 판 테마 반응: 용암·화산 판 burn, 얼음 판 freeze 또는 slip, 물 판 swim, 낭떠러지 근처 배치면 dangle. 피해·점수 없음(구경거리). 크기는 주인공 무릎~허리, 발은 땅에 붙게. 공격 맞아도 아무 일 없이 도망만.
끝나면: npm run build:phaser 성공 → phaser 브랜치 커밋·푸시 "수우쿠렛 연결".
