[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만든다. 이미 있는 결과물은 다시 만들지 않는다.
- 필요한 문서만 읽고, 긴 문서는 해당 항목만 본다. 참고 이미지는 꼭 필요한 1~2장만 넣는다.
- 검증용 스크립트·보고서·메모 파일을 따로 만들지 않는다. 저장 확인은 파일 존재와 크기만 본다.
- 설명·요약을 길게 쓰지 않는다. 끝나면 결과 파일 목록 한 줄만 출력한다.
- 질문하지 말고 끝까지 진행한다.

- 스프라이트 시트를 그릴 때: 프레임 사이 간격을 넓게(칸마다 사방 여백 칸 크기의 15% 이상), 그림이 칸 밖으로 나가거나 옆 칸에 닿지 않게, 배경은 진짜 투명.


[구현] 층층 바위벽 지형 연결 + 첫 로딩 경량화 (115) — src·art-src·public 파일 삭제 금지(필요시 _old로 이동)
1. public/assets/terrain-v11 (113) 을 1~15판 지형에 연결. 4~15판은 manifest 색 변형 사용. 바닥 긴 땅 + 2~3층 바위, 벽 속 굴 입구(동굴 입장), 사다리는 아래층 윗면~위층 윗면 전체 길이로 늘려서.
2. 미리보기에 타일 사이 세로 어두운 이음선이 보임: 타일 가장자리 2~4px 겹쳐 그리기 등으로 이음선 0.
3. 1~15판 모두 시작→보스문까지 걸어서·점프·사다리로 통과 가능한지 코드 시뮬로 확인 (막힘 0).

5. vite emptyOutDir=true 로 되돌림 (dist는 빌드 결과물이라 매번 새로 만드는 게 정상, 이건 삭제 금지 대상 아님).
6. npm run build 성공, dist 용량·첫 로딩 용량 보고.
