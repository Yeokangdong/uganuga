[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만든다. 이미 있는 결과물은 다시 만들지 않는다.
- 필요한 문서만 읽고, 긴 문서는 해당 항목만 본다. 참고 이미지는 꼭 필요한 1~2장만 넣는다.
- 검증용 스크립트·보고서·메모 파일을 따로 만들지 않는다. 저장 확인은 파일 존재와 크기만 본다.
- 설명·요약을 길게 쓰지 않는다. 끝나면 결과 파일 목록 한 줄만 출력한다.
- 질문하지 말고 끝까지 진행한다.

- 스프라이트 시트를 그릴 때: 프레임 사이 간격을 넓게(칸마다 사방 여백 칸 크기의 15% 이상), 그림이 칸 밖으로 나가거나 옆 칸에 닿지 않게, 배경은 진짜 투명.


[구현] 15판 구성 + 점검 수정 1차 (110)
codex\reports\LEAD_개선점.md 참고. 파일 삭제 금지(필요하면 _old로 이동).
1. 판 수 20 → 15. 15판만 final, 15판 보스 처치 시 누가 공주 구출 엔딩 → 결과 화면. 1~3판은 정글·화산·빙하 순서 유지, 4~15판은 기존 테마 재배치로 난이도 점진 상승.
2. 보스 체력바: 화면 하단 boss-meter 제거, 머리 위 게이지만.
3. X 던지기 제거 (input/entities/HUD 안내까지). 조작은 ←→ 이동, ↑ 점프, Space 공격 (2P A/D, W, F).
4. 일반 글자로 나오는 문구(READY, 이동 안내, 보스 이름, HUD 라벨 등)를 기존 그림 글자로 교체. 그림이 없는 문구는 목록만 codex\reports\구현_110_글자목록.md 에 적고 임시로 기존 그림 글자 조합 사용.
5. npm run build 성공 확인.
결과: codex\reports\구현_110.md 10줄 이내.
