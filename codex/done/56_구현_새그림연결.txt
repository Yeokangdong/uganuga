[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만든다. 이미 있는 결과물은 다시 만들지 않는다.
- 필요한 문서만 읽고, 긴 문서는 해당 항목만 본다. 참고 이미지는 꼭 필요한 1~2장만 넣는다.
- 검증용 스크립트·보고서·메모 파일을 따로 만들지 않는다. 저장 확인은 파일 존재와 크기만 본다.
- 설명·요약을 길게 쓰지 않는다. 끝나면 결과 파일 목록 한 줄만 출력한다.
- 질문하지 말고 끝까지 진행한다.


구현 담당. 새 원화를 tools\pack_art.py 로 배포(public\assets, art.json)에 연결하고 게임에 써라. 기존 그림 파일은 남겨 두고, 게임은 새 그림을 쓴다.
- 주인공: art-src\sheets\uga_sheet2·buga_sheet2(+json) — 걷기8·대기4·점프4·휘두르기6·피격2·사다리4.
- 몬스터: dino1~3_sheet(+json) — 스테이지별 공룡 3종, 걷기·공격·맞음·기절·쓰러짐 프레임 사용.
- 보스: boss1~3_dino(+json). 보스3 이름은 "만년설" 유지.
- 지형: art-src\tiles\terrain1~3(+json) 로 바위 벽·흙 띠·굴·나무 사다리·바닥을 그린다(level.ts).
- 글자: art-src\ui\word_*.png(words.json)·font_digits.png 로 화면 글자·숫자를 전부 그림으로(HUD·배너·타이틀·결과). word_woolly_mammoth 은 보스3 이름표로 그대로 사용.
- FOOD 막대 그림(food_frame·fill·full)을 HUD에 놓아만 둔다(규칙은 다음 작업).
큰 PNG는 webp로 줄여라. npm run build 통과. 보고 codex\reports\구현_56.md 5줄. 끝.
