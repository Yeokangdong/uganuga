[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만들고 기존 결과물은 재생성하지 않는다. 검증용 스크립트·보고서·메모를 따로 만들지 않으며 저장은 존재·크기만 확인한다.
- 필요한 문서·항목만 읽고 참고 이미지는 필수 1~2장만 사용한다. 질문 없이 끝까지 진행하고 설명은 짧게, 완료 시 결과 파일 목록 한 줄만 출력한다.
- 스프라이트는 칸마다 사방 15% 이상 여백, 칸 밖·옆 칸 침범 금지, 실제 투명 배경을 지킨다.
- 긴 소스·로그는 검색 후 필요한 범위만 읽고, 이미 읽은 내용·전체 목록을 반복 출력하지 않는다.
- 빌드는 완료 확인에 1회 실행하고 이후 변경·실패가 있을 때만 재실행한다. 이미지 생성·열기는 필요한 대상만 처리한다.
- 정기 토큰 점검은 매 10번째 작업마다 1회만: 로그 끝 tokens used 상위 10개와 원인 확인·규칙 보완(이번은 141번 특별 점검).


[캐릭터] 몬스터 표정 누그러뜨리기 (230) — 대표 지적: 「몬스터 그림체가 좀 안 맞는다. 지금 표정에서 조금만 누그러뜨려」.
기준 그림: codex\inbox\uga_walk_ludo.png (주인공, 둥글고 귀여운 만화체, 굵은 갈색 외곽선, 평면 채색).
대상: Phaser 판(src-phaser)이 쓰는 일반 몹·패턴 몹(원숭이 등)·보스 전부.
할 일: 지금 그림을 바탕으로 표정만 "조금" 순하게 — 찌푸린 눈썹 각도 줄이기, 눈 조금 둥글게, 이빨·입 벌림 작게, 핏발·과한 주름 빼기. 무섭지만 귀여운 정도(고인돌 Joe & Mac 몹 느낌). 몸 모양·색·크기·프레임 수·발 위치·투명 여백은 그대로.
외곽선 굵기·채색 방식은 기준 그림에 맞추기.
원본 수정·삭제 금지 → 고친 그림은 새 파일(같은 이름 + _soft)로 src-phaser 쪽 에셋 폴더에 저장하고, src-phaser 에서 _soft 를 쓰도록 연결만 바꿈. main·gh-pages 건드리지 말 것. 창 띄우지 말 것. .bat 금지. 다른 작업 큐에 넣지 말 것. 토큰 절약.
끝나면 npm run build:phaser 성공 → phaser 브랜치 커밋·푸시 "몬스터 표정 완화".
결과: codex\reports\구현_230.md 5줄 + 전/후 비교 한 장 codex\reports\shots\230_전후.png (몹마다 왼쪽 원본·오른쪽 수정, 주인공 기준 그림 함께).
