[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만든다. 이미 있는 결과물은 다시 만들지 않는다.
- 필요한 문서만 읽고, 긴 문서는 해당 항목만 본다. 참고 이미지는 꼭 필요한 1~2장만 넣는다.
- 검증용 스크립트·보고서·메모 파일을 따로 만들지 않는다. 저장 확인은 파일 존재와 크기만 본다.
- 설명·요약을 길게 쓰지 않는다. 끝나면 결과 파일 목록 한 줄만 출력한다.
- 질문하지 말고 끝까지 진행한다.

- 스프라이트 시트를 그릴 때: 프레임 사이 간격을 넓게(칸마다 사방 여백 칸 크기의 15% 이상), 그림이 칸 밖으로 나가거나 옆 칸에 닿지 않게, 배경은 진짜 투명.


[구현] 보스바·동굴·첫 로딩 + 배포 (130) — 파일 삭제 금지(필요시 _old로 이동). 창 띄우지 말 것. .bat 실행 금지.
1. 보스 체력바는 보스 머리 위 게이지만. 화면 하단 보스 막대(boss-meter 등)는 표시 제거.
2. 동굴 방마다 천장에서 실에 매달려 오르내리는 거미 1마리 이상(닿으면 피해), 벽 횃불 2개(불꽃+주변 빛). 1판은 거미 느리게.
3. 첫 로딩 경량화: 시작 화면+1판에 필요한 그림만 먼저 받고, 나머지 판 그림은 그 판 시작 때 로딩(로딩 화면은 기존 그림 글자 사용). 원본 그림 파일은 그대로 둠.
4. 위 외 게임 내용 변경 금지. npm run build 성공. 첫 로딩 용량(MB) 측정.
5. 배포: robocopy dist _pages /MIR /XD .git ; .nojekyll 유지 ; cd _pages ; git add -A ; git commit -m "보스바 동굴 로딩" ; git push -f origin gh-pages
6. 메인: git add -A ; git commit -m "보스바 머리 위만, 동굴 거미·횃불, 첫 로딩 경량화" ; git push origin main
결과: codex\reports\구현_130.md 5줄 (첫 로딩 용량 포함).
