[팀 공통 규칙 — 토큰 절약]
- 지시받은 파일만 만든다. 이미 있는 결과물은 다시 만들지 않는다.
- 필요한 문서만 읽고, 긴 문서는 해당 항목만 본다. 참고 이미지는 꼭 필요한 1~2장만 넣는다.
- 검증용 스크립트·보고서·메모 파일을 따로 만들지 않는다. 저장 확인은 파일 존재와 크기만 본다.
- 설명·요약을 길게 쓰지 않는다. 끝나면 결과 파일 목록 한 줄만 출력한다.
- 질문하지 말고 끝까지 진행한다.

- 스프라이트 시트를 그릴 때: 프레임 사이 간격을 넓게(칸마다 사방 여백 칸 크기의 15% 이상), 그림이 칸 밖으로 나가거나 옆 칸에 닿지 않게, 배경은 진짜 투명.


구현 담당. 실장이 돌려 본 화면 codex\ref\check_start.jpg.
1) 너무 무겁다: 게임이 원본 PNG(글자 그림 하나 1~2MB, 표지판 3MB, 꿈 장면 2.7MB 등)를 그대로 불러와 켜고 6초 넘게 검은 화면이다. 모든 그림을 tools\pack_art.py 로 화면에 쓰는 크기에 맞게 줄여 webp(품질 85)로 바꿔 불러와라(글자 그림은 가로 400px 이하, 배경·꿈 장면 960px, 시트는 프레임 크기 기준). public\assets 전체 30MB 이하 목표.
2) 불러오는 동안 검은 화면 대신 "불러오는 중" 막대(간단히)를 보여라.
3) STAGE 돌 표지판이 화면 왼쪽 아래에 작게 나온다 → 기준 codex\ref\ref_game3.png 처럼 주인공 바로 옆 땅 위에 크게(주인공 키의 약 2배 폭), "준비!"는 화면 가운데 위쪽에 표지판과 겹치지 않게.
