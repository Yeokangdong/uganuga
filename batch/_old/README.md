# 우가누가 팀장 체제 배치 파일

| 파일 | 하는 일 |
|---|---|
| 작업관리자_켜기.vbs | 작업 관리자(Codex 배차기)를 창 없이 켬. PC 켤 때마다 한 번 |
| 작업관리자_끄기.bat | 작업 관리자 끄기 |

| 페이지배포.bat | 빌드해서 GitHub Pages에 배포 |
| 게임켜기.vbs | PC에서 게임 띄우기 (http://localhost:4173) |

## 흐름
작업넣기 → 담당(Codex) → 개발팀장 검수 → 실장(Claude) 확인 → 대표

- 작업 파일: D:\99.Work\Uganuga\codex\queue
- 보고서: D:\99.Work\Uganuga\codex\reports
- 결정 기록: D:\99.Work\Uganuga\codex\DECISIONS.md

## 팀장 체제 자동 수행 (작업 관리자 v3)
- 구현 작업이 끝나면 → 개발팀장 검수가 **자동으로** 큐에 들어감
- 검수 보고서(LEAD_번호.md) 첫 줄이 "통과"면 끝, "지적"이면 → 구현 수정 작업이 **자동으로** 들어감
- 수정 → 검수를 최대 3번 반복, 그래도 지적이 남으면 멈추고 실장이 확인
- 자동 진행 기록: D:\99.Work\Uganuga\codex\reports\AUTO_팀장체제.md
